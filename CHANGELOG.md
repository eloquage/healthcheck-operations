# Changelog

All notable changes to `healthcheck-operations` will be documented in this file.

## v0.1.6 - 2026-11-03

Release the package with Composer identity under the eloquage vendor namespace. This release contains the package metadata and documentation rename; runtime behavior is unchanged.

## 0.1.5 - 2026-10-23

- Support Laravel 12 and 13 on PHP 8.3+.
- Honor the required backlog setting and fail if the upstream manager cannot read state.
- Constrain the one-time-operations dependency to its supported 1.x series.
- Add package banner artwork and concise setup and usage examples.
